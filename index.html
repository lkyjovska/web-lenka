Docker cheat sheet

Los comandos que hemos usado en la Práctica 12 · SRI & SAD · 2º Redes

Servida desde un contenedor con mi propia imagen: lkyj004/lenka-web

📦 Imágenes

La receta ya cocinada.

docker pull nginx:alpine
Descarga una imagen de Docker Hub
docker images
Lista las imágenes del servidor
docker build -t usuario/img:1.0 .
Construye una imagen desde un Dockerfile
docker push usuario/img:1.0
Sube la imagen a Docker Hub
docker rmi nginx:alpine
Borra una imagen

🚀 Contenedores

El plato servido con esa receta.

docker run -d --name web img
Crea y arranca un contenedor en segundo plano
docker ps · docker ps -a
En marcha · todos
docker logs --tail 20 web
Últimas líneas del registro
docker exec -it web sh
Entra dentro del contenedor
docker stop web · docker rm web
Parar · borrar

🌐 Redes y puertos

Cómo se hablan los contenedores y el exterior.

-p 127.0.0.1:8090:80
Publica el puerto 80 del contenedor en el 8090 local
EXPOSE 80
Solo documenta el puerto: no abre nada
docker network ls
Lista las redes
docker network create proxy
Red propia: los contenedores se ven por nombre

💾 Volúmenes

Para que los datos sobrevivan al contenedor.

-v datos:/app/data
Volumen con nombre (lo gestiona Docker)
-v ./carpeta:/data
Bind mount (una carpeta tuya del servidor)
docker volume ls
Lista los volúmenes

🧩 Docker Compose

Todo escrito en un archivo.

docker compose up -d
Arranca el stack
docker compose down
Para y borra los contenedores del stack
docker compose logs -f
Sigue los registros

🔎 Inspeccionar

Mirar qué pasa por dentro.

docker inspect web
Detalles: IP, montajes, salud
docker stats --no-stream
CPU y memoria
docker system df
Espacio que ocupa Docker
